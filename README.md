## Tentang Proyek

Ini adalah repositori kode sumber untuk website portofolio pribadi saya. Dibangun dengan desain modern dan animasi yang *smooth* untuk memberikan pengalaman digital visual yang mengesankan.

## Fitur Utama

- **Animasi & Interaksi Modern:** Menggunakan perpaduan **GSAP** dan **Split-Type** untuk menghadirkan animasi teks dan transisi halaman yang *smooth* dan premium.
- **Smooth Scrolling:** Mengintegrasikan **Lenis** untuk memberikan efek gulir yang elegan di seluruh halaman website.
- **Performa Tinggi:** Ditenagai oleh **Astro**, meminimalisir penggunaan *JavaScript* pada sisi klien sehingga waktu *loading* sangat cepat.
- **Desain Cantik & Responsif:** Menggunakan **Tailwind CSS v4** untuk membangun antarmuka yang modern, rapi, dan sepenuhnya responsif (Desktop, Tablet, Mobile).

## Stack Teknologi

- [Astro](https://astro.build/) - Meta-framework super cepat
- [Tailwind CSS](https://tailwindcss.com/) - Framework utility-first CSS
- [GSAP](https://gsap.com/) - Ekosistem animasi JavaScript
- [Lenis](https://lenis.studiofreight.com/) - Smooth scroll library
- [Split-Type](https://github.com/lukePeavey/SplitType) - Teks split tool untuk animasi
